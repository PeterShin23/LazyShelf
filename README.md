# TheShowcase.me
This is an automated photography portfolio website where a user, who agrees to share their Instagram data, can have their own personalized photography portfolio to display to others! This is a passion project where I as a photographer want to have a dedicated website to display my work but am too lazy to maintain both an Instagram and a separate website. There are definitely others like me out there, and I hope to provide an affordable and easy-to-maintain approach to showing off their individual creativity.

I currently own the domain, theshowcase.me, but the website has been taken down for now because it costs a little too much to keep it afloat. My plan is to redeploy this website when I don't mind spending $20 a month :).
